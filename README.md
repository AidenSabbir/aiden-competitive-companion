# Aiden Competitive Companion

Import programming problems from Competitive Companion into VS Code.

## Features

- Starts a local HTTP listener for Competitive Companion
- Creates solution file from your template
- Writes sample input to `input.txt`
- Supports configurable template directory, host, port, and language map

## Settings

- `aidenCompetitiveCompanion.host`
- `aidenCompetitiveCompanion.port`
- `aidenCompetitiveCompanion.templateDirectory`
- `aidenCompetitiveCompanion.inputMode`
- `aidenCompetitiveCompanion.languageMap`

## Usage

1. Run extension in development (F5) or install VSIX.
2. Configure Competitive Companion to send to `127.0.0.1:27121`.
3. Open a workspace folder in VS Code.
4. Click Competitive Companion button on a supported problem page.
